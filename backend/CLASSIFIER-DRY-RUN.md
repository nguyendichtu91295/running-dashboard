# Experimental classifier report

Run `node src/classifier-report.mjs` from the backend directory. It reads the local `.env` Garmin key, retrieves the last 365 UTC calendar dates of running activity summaries and downloads original FIT ZIPs into `.classifier-dry-run/`. Supply `--db /path/to/activities.sqlite` to use all rows from an existing database opened read-only instead of searching the API. ZIPs are reused on subsequent runs; remove individual cache files only when a fresh download is wanted. Reports are `report.json` and `report.md` in that ignored directory.

The historical comparison is `dashboard/public/data/running-trends.csv`; title and local date are only tentative matching keys and duplicate keys are ambiguous. API retrieval, download and decode failures are shown in the report. A complete input set cannot be guaranteed if the upstream API omits records. Laps without usable timing or distance, threshold boundaries, conflicting evidence and races remain unresolved. A potential match is not a stable activity identity. The JSON contains individual normalized laps and machine-readable results; the Markdown is for review. Review the assumptions and reports before any production use. This tool never writes classification results to the database or starts the server or sync service.
